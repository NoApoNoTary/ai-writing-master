# 读者价值双步骤

本流程只解决两个问题：读者正在面对什么，以及文章承诺带来什么变化。

## 适用范围

仅当文章的主要目的包含以下任一项时启用：

- 解释一个概念或现象
- 帮助读者判断、选择或比较
- 解决一个具体问题
- 提供方法、教程或行动指导

以下内容默认跳过：

- 故事、随笔、日记和个人表达
- 以情绪共鸣、娱乐或审美体验为主的内容
- 吐槽、段子和普通 X 短帖

观点文章和个人思考可以轻量使用，由任务本身决定。跳过时不需要寻找替代框架，按文章自身目的自然写作即可。

## 1. 读者价值定义

只填写三项：

```markdown
## 读者价值定义

- 目标读者：
- 当前问题：
- 阅读后的具体变化：
```

要求：

- 目标读者必须描述具体状态，不使用“所有人”“普通用户”等宽泛标签。
- 当前问题描述读者正在面对的困惑、选择困难、理解障碍或执行问题。
- 阅读后的变化应当可感知，例如理解更清楚、判断更准确、方法更具体或下一步更明确。

## 2. 价值承诺

将读者价值定义压缩成一句话：

```text
读完这篇文章，[目标读者] 将能够 [具体变化]，从而 [进一步价值]。
```

允许的承诺类型：

- 理解型：读者会更清楚两个事物之间的关系。
- 判断型：读者能判断某种方法、产品或选择是否适合自己。
- 行动型：读者能按照文章提供的方法完成下一步。

价值承诺是内部写作方向，不直接作为文章开头，也不要求原样出现在正文里。

## 最小检查

1. **具体吗？** 换成任何主题都成立的描述需要重写。
2. **有变化吗？** 只有“了解、认识、知道”时需要进一步明确。
3. **能指导正文吗？** 如果不能帮助决定内容取舍，说明承诺仍然太宽。
