## 1. 交付范围

## 3. 合同覆盖

`tests/test_style_learning.py` 覆盖：

1. Goal A canonical empty Style 字节与 hash 不变；
2. candidate 精确字段、NFC、SHA、路径、dimension、scope、snippet/diff_ref；
3. stable ID、revision 1、双 hash、重复 propose 幂等；
4. observation 目录和文件 symlink 防护；
5. list 排序和 status filter；
6. accepted/rejected revision 2、RFC3339、同决定幂等、相反决定冲突；
7. proposed/rejected 不改变 Style；
8. 多 accepted 规则排序、revision、hash 和 observation refs；
9. accepted observation 已落盘而 Style 写失败后的 read/snapshot/decide reconcile；
10. Style 或 observation 损坏、丢失或终态内容改变时保留最后有效 Style；
11. 任务 N Snapshot 字节不变，N+1 只包含 accepted rule；
12. frozen ready Style 篡改与坏类型返回稳定错误；
13. 并发 propose 和相反 decide 由现有 flock 串行化。

`tests/test_learn_cli.py` 覆盖 JSON happy path、文本输出、missing/malformed/non-standard JSON、决定参数互斥、`unknown_id`、机器可读错误和 direct-module help。
